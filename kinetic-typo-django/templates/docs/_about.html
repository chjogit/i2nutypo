Kinetic Typo Studio란

영상 제작 경험이 없는 사람도 음원과 가사만으로 키네틱 타이포그래피 영상을 만들 수 있게 돕는 웹 편집기입니다. 가사 싱크, 글자 움직임, 테마 연출, 내보내기까지 한곳에서 하고, 모든 처리는 사용자의 브라우저 안에서 이뤄집니다.

어떻게 동작하나

  1. 페이지: Django(5.2)가 Jinja2 템플릿으로 첫 화면, 단계별 편집기, 설명서, 라이선스 페이지를 내줍니다. 데이터베이스는 쓰지 않습니다.
  2. 편집기: TypeScript·React로 만든 편집기가 하나의 번들(static/js/studio.js)로 붙고, 템플릿이 알려 주는 단계(입문·기본·숙련)에 맞춰 기능을 켭니다.
  3. 렌더링: 미리보기와 내보내기가 같은 Canvas 렌더러를 씁니다. 영상 인코딩은 WebCodecs, ProRes는 FFmpeg(WebAssembly)로 합니다.
  4. 자동 싱크: 브라우저 안에서 Whisper로 노래를 인식하고, 알고 있는 가사를 발음 기준으로 정렬합니다. 원하면 먼저 보컬을 분리합니다.
  5. 저장: 작업 내용은 브라우저 저장소에 남고, 서버에는 아무것도 저장하지 않습니다.

쓰는 오픈소스

  • 화면·상태: React, Zustand, Tailwind CSS
  • 모델 실행: Transformers.js, ONNX Runtime Web, @audio/neural-separate
  • 영상: mediabunny(MP4·WebM), ffmpeg.wasm(ProRes, 필요할 때만 받음)
  • 서버: Django, Jinja2
  • 글꼴: Google Fonts에 공개된 무료 글꼴 31종(SIL OFL, 일부 Apache-2.0)을 이 사이트에서 직접 내보냄
  • 무료 배경 영상: Mixkit 무료 라이선스 영상(고를 때만 받음)

편집기 구조는 오픈소스 영상 편집기 OpenCut에서 아이디어를 얻었지만, 코드는 가져오지 않고 직접 작성했습니다. 글자 움직임은 널리 쓰이는 모션그래픽 기법(탄성·감속 곡선, 보색 반전 등)을 Canvas 코드로 직접 구현한 것이고, 테마 연출과 그림도 모두 코드로 그렸습니다.
